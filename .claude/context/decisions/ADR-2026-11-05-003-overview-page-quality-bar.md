# ADR-2026-11-05-003: 圖解畫面保留現行畫布互動，專修「不理想資料」下的呈現，並以 artifact 品質加上髒資料驗收

## 背景

使用者看過現行 `templates/overview/index.html` 套上乾淨範例資料的預覽（「範例電商」：6 個模組、3 個群組、
每個任務都對到模組），他對那個版面和互動是滿意的。他明確指定的互動形式是「畫布＋點模組後右側欄顯示說明」。

品質落差出在 for-query 這種**髒資料**。查程式碼後找到的根因：

| 症狀 | 根因（現行 index.html） |
|---|---|
| 未分組的模組疊在一起 | `layout()` 第 206 行：`gi[m.group] \|\| 0` 讓不在 groups 裡的模組套用第 0 組的位移 |
| 連線、標籤畫到畫布外 | 第 223–231 行的全圖範圍 `ALL` 只看群組框；未分組的模組、貝茲曲線、標籤都沒算進去 |
| `<br/>` 原樣顯示 | mermaid 標籤沒有正規化，SVG `<text>` 直接印出原字串 |
| 長名稱溢出、互相疊 | 第 262、269、278 行：名稱、路徑、任務列都是固定寬度 `W` 的單行 `<text>`，沒有截斷 |
| 每張卡重複印「沒有…」 | 第 269、270、280 行：每張卡各自印空狀態字串 |
| notices 太佔版面 | `#notices` 每一則都獨立成一列，常駐在頂端 |

所以問題不在畫法，在資料正規化與邊界情況。另外一個問題是：參考的 hook 地圖 artifact 在
token 化、深淺雙主題、字型層次上比現行頁面細緻，這部分也要拉齊。

## 決策

1. **互動模型與繪圖方式不變**：點點底紋的 SVG 畫布、平移縮放、小地圖、縮放分層（縮小時只看燈號）、
   點模組開右側詳情、點檔案飛到所屬模組、節點不可拖
2. **專修不理想資料**（細節見設計提案第 6.2 節）：
   - 資料正規化：腳本端把標籤去 HTML、`<br>` 換成空白，頁面端再做一次防禦
   - SVG 文字自動截斷：用 `getComputedTextLength` 量寬度，名稱最多兩行、其餘欄位一行，結尾加「…」；完整內容放在 `<title>` 與右側欄
   - 「未分組」成為獨立一欄
   - 全圖範圍改用 `world.getBBox()` 量實際內容
   - 空狀態一律收斂到區塊層級，只說一次
   - notices 收成一列摘要、可以展開
3. **視覺細緻度對齊參考 artifact**：語意 token、`data-theme` 雙向覆寫、字型角色、資訊層次（Q1–Q14，見設計提案第 6.1 節）。
   與參考頁**刻意不同**的一點是：**不載 Google Fonts CDN**（`file://` 要能離線開，金融環境也不該連外），
   改用 `fonts-cjk.md` 的系統字型順序
4. **驗收用兩組資料**：乾淨的範例電商（不能比現在退步），加上仿 for-query 的髒資料
   （C4 格式 5.1、WBS 沒有模組欄、30 多個任務、長中文名、標籤含 `<br/>`、未分組模組、notices 多則）。兩組都要達到 artifact 的品質

## 替代方案

| 方案 | 優點 | 否決理由 |
|---|---|---|
| 改成 HTML 卡片＋SVG 連線（本 ADR 第一版提議） | CSS 原生處理換行與截斷 | 使用者已確認現行互動與畫法是他要的；等於整頁重寫，乾淨資料下的現有品質反而有退步風險 |
| 改用 mermaid.js／Cytoscape | 版面現成 | 1–3MB，超過 80KB 的上限；而且會換掉使用者指定的互動 |
| 維持現狀，只修資料 | 改動最小 | 骨架改從程式碼掃出來之後，還是會有未分組、長路徑、全空資料的情況，邊界 bug 依然存在 |

## 後果

**得到：** 使用者滿意的互動完整保留；髒資料下不再疊卡、不溢出、不畫出界、不洗版；有雙主題與一致的 token。

**犧牲：** SVG 文字截斷要在瀏覽器量字寬，首次繪製多花一點時間（40 個模組以內可以忽略）；
頁面大小預計從 34.5KB 長到約 40–45KB，仍在 80KB 上限內。

**何時該重新考慮：** 模組數常態超過 100 個；或文字截斷在某個瀏覽器量不準（例如字型還沒載入完就量）。

## 確認方式

- [C] `check-counts.sh`：`index.html` ≤ 80KB；`:root`／`[data-theme]` token 區塊以外沒有 hex 色碼；沒有外部網址
- [T] `overview.sh` 輸出的 data.js 裡，所有 `name`、`label` 都不含 `<`、`&lt;`、`\n`（標籤正規化）
- [M] Playwright 開兩組 fixture，跑固定的檢查腳本（設計提案第 6.3 節）：
  - 卡片外框互不重疊
  - `world.getBBox()` 在全圖範圍內
  - 畫面文字不含 `<br`
  - 同一句空狀態文字最多 1 次
  - 每個 `<text>` 的寬度 ≤ 卡片內寬
  - 390px 下頁面沒有水平捲軸
- [M] 兩組資料 × 390／1440 × 淺色／深色，共八張截圖，和參考 artifact 並排，由使用者確認
