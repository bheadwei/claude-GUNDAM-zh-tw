# ADR-2026-11-09-001: 專案圖解畫面 `index.html` 的大小上限從 64KB 調回 80KB

## 背景

`check-counts.sh` 擋 `.claude/templates/overview/index.html` 的大小。ADR-2026-11-05-003 原訂 80KB；
X9 先收緊成 50KB（當時 45KB 放得下），ADR-2026-11-06-002 為了模組展開調成 64KB。
`adhoc-2026-11-09-overview-readability` 階段 1 做完時檔案 63,167 bytes，只剩約 2.3KB，
階段 2（任務圖目錄）與階段 3（地圖可選計畫）預估還要 5–8KB。

## 決策

上限調回 ADR-2026-11-05-003 原訂的 80KB（`check-counts.sh` 的 65536 → 81920、頁首註解同步）。

## 考慮過的替代方案

| 方案 | 不選的原因 |
|---|---|
| 維持 64KB，先壓縮既有 CSS／JS | 多一個階段、程式更難讀，且不保證壓得出 5–8KB |
| 目錄與選計畫拆成另一支 `.js` | 多一個要複製、要內嵌進 artifact 的檔（ADR-2026-11-06-002 當初不選的同一個理由） |

## 後果

- 畫面是本機以 file:// 開的單檔，多 16KB 對載入沒有可感影響
- 再超過 80KB 時不再調上限：屆時改拆檔或瘦身，並另寫 ADR
