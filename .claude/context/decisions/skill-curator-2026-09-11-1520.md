## 改了什麼

1. **新增 `.claude/hooks/lib/cmd-segments.sh`**（唯一來源）
   - `cmd_segments <cmd>` — 沿 `&& || ; |` 切段、剝前導 `( {`、只留 `^git[[:space:]]`
   - `cmd_match <str> <ERE>` — 前後補空白再 `grep -qE`（`merge-base` 因此不是 `merge`）
   - 有意留下的漏網（`sudo git …`、`env X=1 git …`、行首就是指令的文件區塊）照抄原註解
2. **`lib/git-backup-gate.sh`** — 刪掉 `_gbg_segments`／`_gbg_m` 的本體，改 source 共用 lib 並改用 `cmd_segments`／`cmd_match`；缺檔時 `return 0`（與它其他「判斷不了就放行」分支一致）
3. **`post-bash.sh`** — 偵測改為切段迴圈算出 `MP_OP`／`MP_SEG`，外層 `case` 的 subject 從 `$CMD` 換成 `$MP_OP`／`$MP_SEG`。
   **刻意沒動**：`[操作類型] 目標 ref` 的格式、`${var:0:100}` 的字元截斷、「衝突的 merge 也要記」、ref 抽取仍在 `$CMD` 上做（`-m "訊息"` 的剝除需要完整指令，切段會被訊息裡的 `;` 切壞）
4. **`hooks/README.md`** — lib/ 樹補齊 + 規範註
5. **`context/learned/2026-09-11-gate-blocks-its-own-fix.md`** — 補「已修」節與全掃結果表
6. **`CLAUDE.md` → `FIXED-LOG.md`** — 該條落差搬家
