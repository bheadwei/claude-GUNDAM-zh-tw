# ADR-2026-11-12-001: 專案圖解畫面 `index.html` 的大小上限從 80KB 調到 128KB，不拆檔

## 背景

`check-counts.sh` 擋 `.claude/templates/overview/index.html` 的大小（現行 81920 bytes，ADR-2026-11-09-001）。
專案圖解改版（`plans/adhoc-2026-11-12-overview-live.md`）要加「現況分頁」：現行約 67KB，預覽量到現況分頁約 +14KB（CSS 約 7KB、JS 約 8KB），
接真實資料約再 +3KB，全放進 index.html 估 84–86KB，超過 80KB。
ADR-2026-11-09-001 寫明「再超過 80KB 時不再調上限：屆時改拆檔或瘦身，並另寫 ADR」——本 ADR 就是那份「另寫的 ADR」，但結論不是拆檔。

這條上限從來不是技術限制：ADR-2026-11-09-001 自己寫「多 16KB 對載入沒有可感影響」。它是**防膨脹護欄**——逼每次加功能時先想一下值不值得。
那麼這次要守住 80KB（拆檔或砍功能），還是把護欄挪到新位置？

## 決策

上限調到 **128KB**（`check-counts.sh` 的 81920 → 131072、頁首註解同步）。**不拆 `now.js`**，現況分頁的 CSS／JS 照舊寫在 index.html 內；
**護欄保留**，只是挪位置。

- 調完後約 84–86KB，留約 42KB 空間
- 範圍只有 `index.html` 一個檔；`data.js`／`live.js` 是產物，大小由 `OVERVIEW_MAX_BYTES` 管，不受本 ADR 影響
- 本 ADR 只取代 ADR-2026-11-09-001 的「上限數字」與「再超過時必須拆檔或瘦身」那句；ADR-2026-11-05-003 的其他品質條件（不載外部網址、不用 module script、色碼只在 token 區）全部照舊

## 替代方案

| 方案 | 優點 | 否決理由 |
|---|---|---|
| 拆出 `now.js`，index.html 留在約 71KB（規劃時推薦） | 守住 80KB；現況分頁自成一檔 | 使用者選不拆。舊的拆檔顧慮其實已大致不成立（見下），但多一個檔仍要多一條 `copy_page` 複製、多一條 `session-start.sh` 補產條件、`check-counts.sh` 守門要擴到兩個檔——為了一個不是技術限制的數字付這些成本不划算 |
| 不拆檔、直接拿掉上限 | 再也不用為大小寫 ADR | 失去防膨脹護欄；頁面只會越長越大，沒有任何時間點逼人回頭瘦身 |
| 砍功能壓回 80KB | 不動上限 | 現況分頁是這次改版的主角，要壓 5–6KB 只能砍動畫或卡片資訊；同等成本換來的只是守住一個非技術數字 |
| 加建置步驟壓縮（minify） | 檔案變小 | 模板刻意沒有建置鏈；壓縮後的 index.html 不能直接讀、不能直接改，`ui-builder` 與人工審閱都會變難 |

### 舊的拆檔顧慮現在還成立嗎

ADR-2026-11-06-002 與 ADR-2026-11-09-001 不拆檔的理由有兩條：

1. **SSH 使用者要整個資料夾下載才看得到**——改用本機 http 網址（ADR-2026-11-12-003）後，瀏覽器透過 port 轉發取檔，檔數不影響使用者，**這條不再成立**
2. **多一個要複製、要內嵌進 artifact 的檔**——審閱 artifact 是開發時由主模型手動內嵌，多一檔多一步；`copy_page`／補產／守門也各多一處。**這條仍成立，但成本小**

所以這次不拆是使用者的取捨（少維護一個檔），不是技術上拆不了。下次真的要拆時，第 1 條已經不是阻力。

## 後果

**得到：**
- 現況分頁照計畫做完，不需要階段 7 多建 `now.js`、不動 `copy_page` 與 `session-start.sh` 的補產條件
- 仍有一條會擋人的護欄，只是位置在 128KB

**犧牲：**
- index.html 變得更長（約 85KB、單檔），`ui-builder` 每次改動要讀的量變大
- 護欄被調過三次（50 → 64 → 80 → 128KB），「上限」的約束力在變弱；本 ADR 用下面的觸發條件補強

**何時該重新考慮：**
- index.html 超過 **112KB**（上限的 7/8）→ 下一個加功能的計畫在規劃時就要評估拆檔或瘦身，不要等撞到 128KB 才處理
- 再超過 128KB → **預設拆檔**（例如把現況分頁拆成 `now.js`），不再調上限；若仍要調，新 ADR 要說明為什麼拆檔不可行
- 審閱 artifact 改成自動產生（不再手動內嵌）→ 拆檔剩下的成本只有 `copy_page`／補產／守門三處，可以直接改拆

## 確認方式

- [C] `check-counts.sh`：`index.html` ≤ 131072 bytes，失敗訊息寫「超過 128KB 上限」；頁首註解同步寫 128KB
- [C] 其餘專案圖解守門（外部網址、module script、hex 色碼）不變，照綠
- [M] `.claude/templates/overview/` 目錄下沒有新增 `now.js`（本 ADR 不拆檔）
