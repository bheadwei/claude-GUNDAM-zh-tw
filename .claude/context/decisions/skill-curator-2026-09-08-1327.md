## 決策

### 1. 內容來源：官方 token 檔，不憑印象

Semrush 有公開的設計系統 **Intergalactic**（`developer.semrush.com/intergalactic`）。
與其從網頁截圖推測，直接取用其 repo 的權威 token 定義：

```
https://raw.githubusercontent.com/semrush/intergalactic/master/semcore/core/src/theme/light.json
```

DESIGN.md 裡幾乎每個數值都有出處：9 階灰、blue/orange/green/red/yellow/violet/pink/salad 各 9 階、
語意 token（`text.*` `bg.*` `border.*` `control.*` `table.th/td.*` `chart.*` `tag.*`
`box-shadow.*` `overlay.*` `z-index.*`）、字級 `fs-50…fs-800`（10→48px）、
行高 `lh-*`（百分比）、圓角 5 階（2/4/6/12/24px）、斷點（320/768/1200/1920）、
duration（100–500ms）、以及**基準單位 `scale-indent = 4px`**。

表格規格（cell padding `spacing-3x` = 12px、compact 降為 `spacing-2x` = 8px、
內容一律上對齊、sticky header、排序整格為目標區）取自 Intergalactic 的 Primary table 文件。
字體：Intergalactic 明載 base font 為 **Inter**；品牌 display face 為 **Factor A**
（marketing 標題與 logotype）。

> Inter 在 `ui-style-compliance` 2.5 是「AI slop」的紅旗之一，但那條的措辭是
> **「無理由用 Inter」**。這裡有理由且已在文中寫明（官方設計系統指定 + 10–14px 密集表格的
> x-height／tabular figures 需求），不算違反。

### 2. 定位：68 份裡唯一把「資訊密度」當第一原則的

其餘多數風格走克制留白。這份刻意反向，並且是可查證的反向——Semrush 的基準單位是
**4px 而不是 8px**，這個結構性決定本身就是為密集儀表板存在的。全文以此為軸：

- 第 1 節開宗明義「螢幕的工作是把盡可能多的決策級資料塞進一個 viewport」
- 「Whitespace Philosophy」小節寫的是**為什麼不能加留白**（adjacency is meaning、
  vertical space 是稀缺資源），而不是留白哲學
- Do's/Don'ts 第一條 Do 是「Fit more on the screen」，第一條 Don't 是
  「Don't add whitespace to *let it breathe*」
- 新增兩個此風格專屬的元件段：**KPI / Metric Card**（160–200px 寬、caption→value→delta
  貼行排列）與 **Filter Trigger / Multi-level Filter Bar**（換行而非收進選單，
  因為 filter state 是數據的 provenance）
- Iteration Guide 第 1 條就是 density check

### 3. 橘藍對比的真實機制（CATALOG 描述的技術根據）

不是「配色有橘有藍」，而是**職責分工**：`brand.primary = orange.400 #ff642d` 只給
brand-primary control（每畫面至多一個），`control.primary.info = blue.400 #008ff8`
才是一般 primary button，`text.link = blue.500 #006dca`。橘色被配給制保護，
所以在四十個元素的畫面上仍有效。這條寫成 Do/Don't 各一條並列進 Iteration Guide 第 2 條。

### 4. 段落標題：一字未改

`mode: mixed` 靠段落標題抽取。9 個 `## ` 標題與 68 份中的 66–68 份完全相同：

```
1. Visual Theme & Atmosphere / 2. Color Palette & Roles / 3. Typography Rules
4. Component Stylings / 5. Layout Principles / 6. Depth & Elevation
7. Do's and Don'ts / 8. Responsive Behavior / 9. Agent Prompt Guide
```

`## 4` 下含 Buttons / Cards & Containers / Inputs & Forms 等子標題，
`## 5` 下含 Spacing System / Grid & Container —— 對得上 1.2 節那張 override 對應表。
Motion 放在 `## 8` 底下的 `### Motion`（與 openai/cursor 同一種放法），未新增頂層段落。

### 5. 沒有重述跨風格通用規則

反 AI slop、動畫紀律、原生 CSS、文案具體性一律不寫——唯一來源是
`ui-style-compliance` 2.5／2.6。本檔只寫 Semrush 特有的事實
（例如 duration token 值是規格，不是「動畫要有目的」那種紀律）。
