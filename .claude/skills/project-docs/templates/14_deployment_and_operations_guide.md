## 3. SLO 與告警

SLI 要寫清楚 good event 與 valid event 與資料來源，不用主觀認定。

| SLI | 目標 | 窗口 |
| :--- | :--- | :--- |
| 可用性（HTTP < 500 的比例） | 99.9% | 滾動 30 天 |
| 延遲（P95） | < [門檻] ms | 滾動 30 天 |

- **Error budget** ＝ 1 − SLO（99.9% → 30 天約 43 分鐘）。連續 4 週耗盡 → 凍結非緊急發布；單一事故消耗超過 20% 月度預算 → 必寫 postmortem
- **告警用 burn rate，長短窗同時成立才觸發**：

| 窗口 | Burn rate | 嚴重度 | 通知 |
| :--- | :--- | :--- | :--- |
| 1 小時 | 14.4x | Critical | Page on-call |
| 6 小時 | 6x | Warning | Page on-call（非深夜） |
| 3 天 | 1x | Warning | Slack／Ticket |
